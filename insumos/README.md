# Insumos externos

Material recebido de fora da análise principal: o briefing do usuário e análises geradas por **outras ferramentas de IA**. Fica guardado para rastreabilidade e para servir de ponto de partida, mas **não é fonte de verdade**.

## Regras de uso

1. **Insumo ≠ fonte.** Nenhuma afirmação de um insumo entra nos documentos de `docs/` sem verificação independente (busca própria com URL, ou leitura direta do material da A&M).
2. **Preservação literal.** Os textos são guardados como chegaram, com um cabeçalho de origem. Correções e críticas ficam na análise crítica, nunca no insumo.
3. **Construção do zero.** O portfólio 2027 deste repositório é construído com o usuário a partir de evidências. Os insumos entram como hipóteses a testar.
